# 现场验证

当前真实 Quest 已在 Gazebo 试用并保存两条完整录制；仍有暂停、停止和完整链路门未关闭，见 [PLAN](../PLAN.md)。
真机未验收。本页是检查项目，具体启动只看 [USAGE](../USAGE.md)。

1. 核对运行源码/配置、后端类型、依赖与环境，记录是否 GUI/headless。
2. 连接但不握持，确认反馈新鲜、Quest 佩戴/前台/右手柄有效；连接和校准不能触发动作。
3. 检查前/右/上与姿态方向，松手保持，重握不追赶旧锚点。
4. 明确 Start Recording，验证 A 保存、B 丢弃、倒计时与 Save & End；只有显式采集写盘。
5. 在已授权环境检查输入丢失、断线、过期与恢复，区分预期保护停止和调度/队列问题。
6. 保存实际输入、参考、反馈、暂停和配置；验证每条提交与 action 对应，任务成功另行标注。
7. 使用[固定验收门](ROG_TRACKING_EXPERIMENT.md)比较跟随、停手、换向、过冲与松手取消。

记录 OS、Quest/相机版本、B 后端与网络条件。RTT 不是端到端响应时间，参考曲线不是实际运动。
全部失败与不足窗口保留，不为过关改时限、删段或对齐平移曲线。
真机阶段另按实验室既有操作/急停流程开展，本任务不自动切换实体后端。
