4,889 条参考、2,917 条实测、1,779 个已执行来源目标。原事件 8 次 engaged / 8 次 hold，
包含三个无提交段；原录制 complete=true、无 recording_error，固定文件 SHA 保留。

旧横移/抬手和停手场景继续必过；两条新真实 Quest 录制见

## 固定评分

所有候选保存相同条件的源码/配置 SHA、模型、步长、初始状态、显示模式和录制设置。
原始输入、参考、实测与停止事件分别保存，报告同一时间轴，不移动曲线或放慢动作。

| 指标 | 计算与通过要求 |
| --- | --- |
| 输入覆盖 | 完整 59 秒 VR 时间线；所有 7,177 条输入都经过回放入口，包括重复输入和原有无效标志。允许原产品最新槽自然覆盖，必须统计覆盖 / 拒绝原因，不强行执行旧包。不得重采样、减速、跳过困难动作。 |
| 跟踪误差 | 同一时刻的关节误差及 FK 末端位置 / 姿态误差，报告 P50/P95/max；不做时间平移。三次中最差的实际位置 P95 比同条件基线降低至少 30%，姿态 P95 不比基线增加超过 1°，各旧用例位置 P95 不退步超过 2 mm。 |
| 跟手延迟 | 分别记录 A 收输入→发目标、B 收目标→提交、目标→实际响应。A 收输入到实际响应的可观测区段 P95 目标 ≤100 ms；不要把 Quest 预测时间、规划器相位或网络 RTT 当作端到端延迟。若数据无法可靠估计，写不可测，不能算通过。 |
| 停手仍握持 | 在原手柄位移范围 ≤3 mm、姿态变化 ≤1°、持续 ≥300 ms 的窗口识别停手，先固定窗口编号再看候选。停手后 250 ms 内进入最终目标 ±5 mm / ±1° 并连续保持 200 ms；若下一次运动提前开始，则标记该窗口不足，不伪造收敛。越过停手输入范围 ≤10 mm；报告所有窗口，不能挑最好的一次。 |
| 松手 / 失效 | 沿用原 cancel/generation 和期限要求；B 确认 hold 后新增提交为 0。真实输入无效造成的预期停止与调度 / 队列造成的非预期停止分列，后者必须为 0。不得自动重握以隐藏失败。 |
| 路径 / 限值 | 旧横移用例越出目标高度带 ≤20 mm；参考位置 / 速度 / 加速度门不变，实测速度超调独立报告。保持关节模型限位，不能只检查上报的导数。 |
| 保存 | 一次完整录制成功关闭，无 queue_full、缺失提交回执或 HDF5 不完整。每条 B 提交与保存 action 对应，正常停止有明确结尾。 |

这些是工程验收目标，不是已通过的结论。如果不可达或不可测，明确保留未达项，不在运行中改门槛。

## 验证顺序

1. 健康门：30 秒只读观察；源有效，RTF 中位数 ≥0.95、P05 ≥0.90，B 间隔 P99 ≤20 ms，不能有 ≥100 ms 间隔。
   GUI/headless 分列；用户已允许无画面数值比较，真实 UI 试用另存证据。
2. 固定 A/B/输入与限值做单因素对照；不重复淘汰的 S0、8 倍加速度或无新证据的前馈/阻抗分支。
3. 完整 VR 入口保留各时间域间隔、packet/epoch 和原验证；只平移统一时间原点，不预读未来点或刷新旧引用。
   原锚点无法认证则写不可复现，新输入的每次握持仍由正常 A 逻辑处理。
4. 最多两套候选交错各三次；全部失败入账。再做十次完整主用例耐久，检查异常暂停、队列与保存。
5. 全部发布门通过后才替换运行版；用户试用满意和 complete=true 均不单独授予发布通过。

固定期限：Gazebo A 观测/B 原引用/B 命令 250/250/250 ms；B 最新源/控制间隔100 ms，
Quest 输入150 ms、本地 IK20 ms/任务100 ms。历史180/200 ms不与当前组混算算法收益。
完整软件与物理负载分开；相同故障重复两次且没有新证据就停止该分支，不能无限重跑挑通过。
