# A 三维姿态显示

Web 操作台 Live status 下方的 **Actual robot posture** 面板默认折叠，点击标题栏展开/收起。
按原流程连接 B、校准并遥操；展开/收起可以随时切换，不需要重连、重新校准或结束录制。
收起面板只停止读取显示快照；停止机械臂仍按原流程松手 / Stop / Disconnect。

默认从机械臂右后方略微俯视；鼠标拖动或方向键旋转、滚轮缩放，Reset view 回到右后方视角。
Reset view 不向机械臂发送动作。仅展开时请求只读三维快照。

## 画面代表什么

- 读取同一 B 连接收到的**实际关节反馈**，不是手柄目标、IK 结果或已经提交的目标。
- 使用 B 握手中的模型尺寸、关节轴和工具坐标，显示简化连杆与末端坐标轴；底面网格只是坐标参考。
- LIVE FEEDBACK 表示反馈有效；失效后冻结并标记 STALE · FROZEN。不会外推运动或重复旧点伪装实时更新。
- 断开或换 B 会话时清除上一台机械臂姿态；B 没有可用模型时明确等待，不套用猜测的模型。
- 支持现有 Gazebo / Intera B 提供的模型与反馈，不传输视频，不显示实验室物体、碰撞或接触情况。

它不是第二套 Gazebo，不需要在 A 或实验室 B 为显示功能安装 ROS / Docker。
画面中的简化外形不等于机器人的碰撞几何；实际现场情况仍需现场观察或摄像头。

## 与遥操的关系

仅更新 A；B 无需因此更新。`display_feedback` 用 NumPy / SciPy 和 B 模型计算只读 FK，浏览器 canvas 绘制，
不新增依赖或模型资源包。显示没有 B 网络连接和运动接口；反馈有效期沿用现有检查，
客户端期限保守扣除请求往返耗时，传输排队不能延长它。

更新代码后重开 A、照常重连 / 校准；会话内展开/收起无需这些操作。

原独立 Qt 三维窗口已于 2026-10-29 随 Qt 界面移除；其软件、Gazebo 开关对照与截图仍保存在
历史证据目录，只作追溯。
Windows 原生与真机现场结果单独验收，不用本机软件截图代替现场验证。
