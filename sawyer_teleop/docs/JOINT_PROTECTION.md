# 关节跳变保护（离线候选）

**A、B 都需更新。** UI 的 `Joint protection (±0.35 rad / 20°)` 默认勾选，
与 Motion option 共用 Apply。未连接时保存供下次连接使用；连接时也采用当前勾选值。
已连接时必须松手、结束录制并等待 B 停止确认才可 Apply；下次握紧使用新设置。
显式关闭会保存到本机配置 `joint_protection_enabled=false`，旧配置缺省为 true。
本轮不启动 ROS/Gazebo/真机，不覆盖已有部署或本机配置。

## 检查位置

阈值为每个关节的绝对差 `abs(q[i] - reference[i]) <= 0.35 rad`，不使用七轴总范数，
不做 ±π 包裹或裁剪。阈值不随名义发送频率放大，也不是速度或加速度限值。

- A：保护启用时，首次以新鲜反馈作为 seed，随后使用上一条通过检查并交给发送槽的目标。
  本地 IK 原有求解边界为模型限位与 seed ±0.35 rad 的交集；官方远端 IK 只接受种子，
  没有同等逐关节硬边界字段，因此 A 在收到结果后检查与 seed 的距离。
  A 发送前还比较上一条通过的目标；失败不推进参考。
- B：远端 IK 返回结果时检查与该请求 seed 的距离，且先复验 generation/期限。
  收到 target 时独立比较上一条接受的目标；首次参考 arm 时的新鲜反馈。
  在实际 publish / native send 前，再比较上一条实际提交的关节参考/目标，
  防止“最新目标覆盖”跳过中间目标而绕过阈值。关节与夹爪动作都在检查之后。
- 超限拒绝并暂停，取消待执行目标；原生模式发 STOP 并等待既有确认流程。
  B 状态/事件保留 stage、joint、target/reference、delta 和 threshold，A 显示暂停原因。
  用户松开后重新握紧，才用新鲜反馈开启新 generation；不自动重试跳变解。

Standard、Fast follow、Intera Cartesian 的 10/20/50/100 Hz，以及关闭插值的遥操路径共用检查。
取消勾选只关闭本轮新增检查；本地 IK 原有边界、模型、限速/加速度、跟随误差、原引用有效期、
停止和断线保护保持原语义。速度/加速度限制仍由各执行路径负责。

Reset arm 的目的地可能远大于 0.35 rad。它显式声明 `motion_purpose=neutral_reset`，
A/B 只允许 B 提供的官方 neutral 目标通过开启的 cubic 受限轨迹；任何其他目的地拒绝。
每个实际执行参考仍检查跳变和原有跟随误差，不允许借回中标志提交任意远目标。

## 录制筛查与取值

完整原始事件、未提交/失败段和时间戳均保留。每段按 source_command_seq 去重，
比较相邻已提交 IK 目标，不能将 100 Hz 插值参考误当作 IK 目标，也不跨握紧段比较。

| 录制 | 相邻目标对 | 最大单关节变化 | 0.20 rad 拦截数 | 0.35 rad 拦截数 |
| --- | ---: | ---: | ---: | ---: |
| 固定实验室用例（7,177 条输入） | 1,774 | 0.288065 rad | 4 | 0 |
| 真实 Quest / Fast follow | 2,196 | 0.066767 rad | 0 | 0 |
| 真实 Quest / Standard | 2,996 | 0.195186 rad | 0 | 0 |

另有两条 Quest 录制共 9 次首目标/握紧反馈比较，全通过；旧实验室用例 5 个有提交段
缺少首目标的确切反馈锚点，不能据此评价首步安全性。全部 8 次握紧和 3 个无提交段仍统计。
未提交或已被旧系统拒绝的 IK 解不在这些目标样本内；旧录制也没有完整确切 seed。
后续 submitted 事件补记 ik_seed，方便现场复核。

模拟固定节拍从原时序选取最新目标时，10 Hz 在实验室/Standard 录制分别有 1/8 次超过 0.35 rad；
Fast 为 0。20、50、100 Hz 三份均为 0。该分析不模拟 FK、租期、原生控制器接替或物理路径，
仅说明低频合并目标可能触发提交前保护。保留各档，现场比较；不因此放宽保护或修改期限。

录制中完整目标与当时最新已记录反馈的距离可达约 1.516 rad（Standard），包含慢速跟随积累。
因此不能把完整目标与反馈的差一律限制到 0.35 rad；这与插值参考的现有 following-error 保护不同。
0.35 rad 是这批录制支持的初始跳变阈值，不是机械安全认证或最终手感结论。

原生 Cartesian 中 q 是目标/关节偏置，内部规划的实际关节路径不由此检查直接约束。
本功能不能保证整个原生物理轨迹始终留在 seed ±0.35 rad 内；真机仍需现场验证。

## 更新与兼容

A/B 都要重新启动加载源码，重连并按原流程校准；本会话 Apply 无需重校准。
无新增依赖、模型、APK 或期限变化。B 最小包模块清单包含 joint_protection。
新版 Operator 始终显式协商开/关，旧 B 缺能力或未确认参数时拒绝握紧，不默默退化。
未协商该扩展的旧客户端/API 和策略回放保持旧语义；不能据此声称旧 A 已获得双端保护。
部署快照是冻结版本，现有快照不会随本轮源码修改自动更新。
